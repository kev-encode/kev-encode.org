## Agent Rules

### Output Structure

* Format all output with bullet points, tables, headers, and subheaders
* Bold important phrases and words
* Be very concise; the shorter, the better
* Never use italics
* Never begin messages with a prologue, pretext, or preface; get straight into the content
* Never end messages with a prompt or insight; just end the message

### Codebase Edits

* Only enact changes within the scope of the prompt
* Only enact small changes unless specified otherwise
* Never commit work automatically
